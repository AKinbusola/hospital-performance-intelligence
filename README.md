# hospital-performance-intelligence

## Project description
This project simulates a hospital management database designed to support operational reporting and healthcare analytics. The database captures patient information, physician assignments, department structure, and appointment scheduling to enable data-driven decision-making.

## Objectives0
- Design a normalized relational database.
- Practice SQL database development using PostgreSQL.
- Analyze appointment activity across departments.
- Support future dashboard development using Tableau.
- Build a scalable healthcare analytics portfolio project.
